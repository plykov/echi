# Echo Loop Language Lab — GitHub Pages Edition

Static Dutch listening-and-repeat practice for GitHub Pages.

## What works here

- 242 Dutch micro-lessons (A1/A2, B1, and B2)
- Browser Dutch voice, shadowing, delayed echo, backchaining, and local recording/replay
- Local progress, review scheduling, practice recommendations, JSON export, and offline shell caching

## Static-edition boundaries

GitHub Pages cannot provide the signed-in application services. This edition therefore keeps learning data in the browser and uses browser TTS. It does not include account sync, human-recording delivery, teacher assignments, or the authoring studios. Recordings never leave the learner's device.

## Deploy

Pushing to `main` runs the included GitHub Pages workflow. The published project URL is expected at `https://plykov.github.io/echi/`.
